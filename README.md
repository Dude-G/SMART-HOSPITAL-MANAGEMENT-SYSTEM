# 🏥 Smart Hospital Management System

A Java console-based application developed to simplify core hospital management tasks through an organized and user-friendly interface. The system demonstrates object-oriented programming principles while providing efficient management of hospital records and operations.

---

## 📖 Overview

The Smart Hospital Management System is an academic project designed to simulate essential hospital management processes. It provides a structured console interface that allows users to manage hospital information efficiently while showcasing Java programming concepts and software design principles.

---

## ✨ Features

- 🏥 Hospital management through a console interface
- 👤 Patient record management
- 📝 Input validation for reliable data entry
- 📂 Organized and structured application workflow
- ⚙️ Object-Oriented Programming implementation
- 📋 Menu-driven navigation

---

## 🛠️ Technologies Used

- Java
- Object-Oriented Programming (OOP)

## 🚀 Getting Started

### Prerequisites

- Java Development Kit (JDK 17 or later)
- IntelliJ IDEA, NetBeans, or any Java IDE

### Clone the repository

```bash
git clone https://github.com/Dude-G/SMART-HOSPITAL-MANAGEMENT-SYSTEM.git
```

### Run the project

1. Open the project in your preferred Java IDE.
2. Compile the project.
3. Run the `Main` class.
